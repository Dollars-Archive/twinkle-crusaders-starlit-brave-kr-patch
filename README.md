## 게임 소개

**트윙클☆크루세이더스 STARLIT BRAVE!!**는 크루세이더스 캐릭터와
여러 게임·애니메이션·소설의 게스트들이 만나는 크로스오버 배틀 어드벤처입니다.

짧은 대화형 진행과 자유로운 팀 편성을 즐기며,
ACT 타임라인에서 행동 순서와 EX 기술을 조합해 전투를 펼칩니다.

### 작품 특징

- 이야기와 전투를 함께 즐기는 **STORY MODE**
- 다양한 팀 조합을 시험하는 전투 중심의 **BRAVE MODE**
- 캐릭터마다 다른 **EX 기술과 고유 특성**
- CPU 대전과 PSP 애드혹 대전
- 캐릭터 설명·음성·튜토리얼 및 데이터 인스톨 기능

[자세한 작품 소개](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/game.html?file=platforms%2Fpsp%2Fgames%2Ftwinkle-crusaders-starlit-brave.md)
